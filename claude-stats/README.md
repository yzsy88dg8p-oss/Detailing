# Claude Stats

Страница со статистикой Claude Code в стиле `/stats`: календарь активности по датам, пиковый час, любимая модель, активные дни, токены, сессии, сообщения и разбивка по моделям. Можно переключать период: всё время, 30 дней, 7 дней.

Скрипт читает историю сессий на вашем компьютере (`~/.claude/projects`) и ничего никуда не отправляет.

```bash
python3 claude-stats/claude_stats.py
```

Нужен только Python 3. Страница `claude-stats.html` откроется в браузере.

Параметры: `--name Имя` задаёт имя в заголовке, `--out путь.html` — куда сохранить, `--no-open` — не открывать браузер.
