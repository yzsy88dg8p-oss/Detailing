# Zero KM Detailing — сайт

Сайт выездной химчистки и детейлинга салона «Zero KM Detailing» (СПб и ЛО).
Сделан по паспорту бизнеса: структура из раздела 13, фирменный стиль из раздела 3,
тексты, цены, регламент и условия выезда из разделов 4–9.

**Готовый сайт лежит в папке [`docs/`](docs/).** Его можно сразу выкладывать на любой хостинг.

## Что внутри

| Вкладка | Файл | Что на странице | Главная кнопка |
|---|---|---|---|
| Главная | `index.html` | заголовок и слоган, прибор-одометр, два смысла «0 KM», 3 преимущества, шторка «до/после», 5 этапов, цены, что нужно от клиента, отзывы | Записаться |
| Услуги и цены | `services.html` | пакет «Комплексная химчистка», доп. услуги, **калькулятор**, чего не делаем, стоимость выезда, блок для таксопарков | Рассчитать |
| Как мы работаем | `process.html` | условия выезда, **11 шагов регламента**, оборудование и химия, что после заказа | Записаться |
| Работы | `works.html` | галерея «до/после» с фильтром по типу салона и марке | Записаться |
| О нас | `about.html` | кто мы, почему выезд, как бережём салон, что не отмоется | Связаться |
| Вопросы | `faq.html` | 8 вопросов из паспорта | Задать вопрос |
| Контакты и запись | `contacts.html` | **форма заявки**, Telegram, WhatsApp, телефон, часы, зона выезда | Отправить заявку |

Плюс `privacy.html` (политика конфиденциальности и согласие на обработку данных) и `404.html`.

На каждой странице есть три постоянные кнопки: Telegram, WhatsApp, звонок
(на телефоне — панель снизу, на компьютере — круглые кнопки справа).

Что ещё сделано:

- мобильная версия в приоритете, проверена на ширине 390 px и 1440 px;
- шрифт Manrope лежит на сайте, Google не нужен;
- SEO: title и description по паспорту, Open Graph-картинка для ссылок в мессенджерах,
  разметка Schema.org (организация, FAQ, «хлебные крошки»), `sitemap.xml`, `robots.txt`;
- фавиконка «круг с 0», иконки для телефона;
- форма: проверка полей, защита от спама (скрытое поле и таймер), фото салона, согласие на обработку данных;
- калькулятор передаёт расчёт прямо в форму заявки;
- учтены настройки «уменьшить движение» и навигация с клавиатуры.

## Как поменять контакты, цены, часы работы

Всё в одном файле — [`src/config.json`](src/config.json):

```json
"contacts": {
  "phone_display": "+7 (000) 000-00-00",   ← как номер выглядит на сайте
  "phone_tel": "+70000000000",             ← тот же номер без пробелов
  "telegram_username": "zerokm_detailing", ← ник без @
  "whatsapp_number": "70000000000",        ← номер для WhatsApp, только цифры
  "hours": "Ежедневно, 9:00–21:00"
},
"prices": { "complex": 6500, "leather": 2500, ... "min_order": 6000 }
```

Цены сами подставятся везде: в таблицу, карточки, калькулятор и разметку для поисковиков.

После правки соберите сайт заново (нужен только Python 3):

```bash
python3 build.py
```

## Как добавить реальные работы

1. Положите фото в `src/static/assets/img/works/`, лучше в формате WebP или JPG, 1600×1200 (4:3).
   «До» и «после» — с одной точки и одного ракурса.
2. Добавьте запись в [`src/data/works.json`](src/data/works.json):

```json
{
  "title": "Сиденья и ковролин после зимы",
  "salon": "fabric",
  "brand": "Kia",
  "car": "Rio",
  "district": "Приморский район",
  "services": "Комплексная химчистка",
  "before": "assets/img/works/kia-rio-before.webp",
  "after": "assets/img/works/kia-rio-after.webp"
}
```

`salon`: `fabric` — тканевый, `leather` — кожаный, `combo` — комбинированный.
Когда появятся свои фото, удалите три записи с `"demo": true` — это демо-примеры формата.
Фильтр по марке появится сам, как только у работ будет заполнено поле `brand`.

## Как добавить отзывы

В [`src/data/reviews.json`](src/data/reviews.json), только настоящие:

```json
[
  { "name": "Анна", "car": "Skoda Octavia", "text": "Текст отзыва", "source": "Яндекс Карты", "url": "https://..." }
]
```

Пока файл пустой, на главной показывается блок «Только настоящие отзывы».

## Форма заявки

Сейчас сайт работает без сервера: после заполнения формы клиент видит готовый текст заявки
и отправляет его вам в WhatsApp или Telegram одной кнопкой.

Чтобы заявки приходили автоматически, укажите в `config.json` адрес сервиса приёма форм
(Formspree, Web3Forms и т. п.) в поле `"form_endpoint"`. Форма отправит туда все поля и фото.
Учтите требование хранить персональные данные россиян на серверах в РФ — уточните у юриста.

## Telegram-бот для записи

В папке [`bot/`](bot/) лежит бот: запись по шагам, заявки с кнопками «Принять / Выполнена / Отказ»,
ответы клиентам из вашего чата и приём заявок с формы сайта. Работает бесплатно на Cloudflare Workers.
Инструкция по запуску — в [`bot/README.md`](bot/README.md).

## Яндекс Метрика

Создайте счётчик на metrika.yandex.ru и впишите его номер в `"yandex_metrika_id"`.
Код счётчика и плашка про cookies добавятся сами. Цели, которые уже размечены:
`click_phone`, `click_tg`, `click_wa`, `form_submit`, `calc_send`.

## Как опубликовать

**GitHub Pages (бесплатно):** Settings → Pages → Source: *Deploy from a branch* →
ветка `main`, папка `/docs` → Save. Через минуту сайт будет по адресу вида
`https://<логин>.github.io/<репозиторий>/`.

**Свой домен** (например, `zerokm-detailing.ru`): впишите его в `site_url` в `config.json`,
пересоберите сайт, создайте файл `src/static/CNAME` с одной строкой — доменом,
и настройте DNS у регистратора по инструкции GitHub Pages.

**Любой другой хостинг:** загрузите содержимое папки `docs/`.

## Перед запуском заполнить

- [ ] Телефон, WhatsApp и ник Telegram (`config.json`). Сейчас стоят заглушки `+7 (000) 000-00-00`.
- [ ] Часы работы (`config.json`). Сейчас «Ежедневно, 9:00–21:00» — это заглушка.
- [ ] ФИО и ИНН самозанятого (`legal` в `config.json`) — для политики конфиденциальности и подвала.
- [ ] Цены: в паспорте это гипотеза, сверьте с Авито и Яндекс Картами (раздел 4).
- [ ] Ответы на вопросы 2, 4 и 8 (время и сушка, зима, гарантия) в `src/data/faq.json`:
      сейчас там осторожные черновики, уточните их после первых заказов.
- [ ] Свои фото «до/после» вместо демо-примеров.
- [ ] Ссылки на Яндекс Карты, 2ГИС, Авито, VK (`links` в `config.json`).
- [ ] Домен и счётчик Метрики.
- [ ] Политику конфиденциальности показать юристу.

## Структура проекта

```
build.py               сборка сайта: src/ → docs/
src/config.json        контакты, цены, домен, счётчик
src/data/              FAQ, работы, отзывы
src/pages/             тексты страниц
src/partials/          шапка, подвал, кнопки связи, иконки
src/layout.html        общий каркас страницы
src/static/            стили, скрипты, шрифты, картинки (копируются как есть)
bot/                   Telegram-бот для записи (Cloudflare Workers)
tools/                 генерация иконок, OG-картинки и демо-фото (нужен Playwright)
docs/                  готовый сайт
```

Иконки, картинку для соцсетей и демо-фото можно перегенерировать:
`NODE_PATH=$(npm root -g) node tools/render-assets.js` (нужен Node.js и Playwright).

Шрифт Manrope распространяется по лицензии SIL Open Font License 1.1 (`src/static/assets/fonts/OFL.txt`).
